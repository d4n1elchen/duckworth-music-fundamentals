1. 同音異名 (Enharmonic Pitches)、加線與八度記號 (8va)

當兩個不同的音名指向同一個實際發聲音高時，我們稱它們互為同音異名／等音 (Enharmonic Pitches)。除了黑鍵（如 F♯ = G♭、C♯ = D♭）之外，由於 E–F 與 B–C 之間沒有黑鍵，因此會產生四組極為重要的白鍵同音異名：

  • E♯（E 升高半音）＝ 白鍵 F；反之 F♭（F 降低半音）＝ 白鍵 E。
  • B♯（B 升高半音）＝ 白鍵 C；反之 C♭（C 降低半音）＝ 白鍵 B。

加線 (Ledger Lines) 與八度記號 (The Octave Sign)

超出五線譜範圍的高低音，會用與五線譜等距的短橫線加線 (Ledger Lines) 延伸。書寫加線有兩條嚴格禁令：① 相鄰音符的加線不可連成一條長線；② 絕不可在音符外側多畫一條加線把音符「夾住」（例如高音譜表上加一間 A5 只需畫下方那條 A5 下方的 A? 不——高音譜表第 5 線是 F5，上加一間是 G5〔完全不需加線！〕，上加一線是 A5〔畫一條線穿過符頭〕，上加二間是 B5〔只畫下方 A5 那一條加線，絕不可在上方多畫一條線封住它！〕）。

為了避免加線過多難以視譜，作曲家常使用八度記號 8va：寫在音符上方時代表實際彈奏高一個八度；寫在音符下方（常加註 bassa，即 8va bassa）時代表實際彈奏低一個八度（如德布西《霧 Brouillards》探索鋼琴極端音域）。

2. 八度音域編號系統 (Octave Identification：A0 至 C8) 與符桿方向

在 88 鍵標準鋼琴系統中，每一個八度編號都從 C 開始、到 B 結束！中央 C 定義為 C4，因此中央 C 往右到下一個 B 為第 4 八度（C4–B4），再往上依序為 C5–B5、C6–B6、C7–B7 與最高音 C8；中央 C 往下則為 C3–B3、C2–B2、C1–B1，而鋼琴最左端低於 C1 的三個音則標為 A0, A♯0/B♭0, B0。（註：部分 61 鍵電子合成器說明書因琴鍵較少，會將中央 C 標為 C3，但樂理標準一律以 88 鍵鋼琴的 C4 = 中央 C 為準！）

💡 Tips & Tools：五線譜上的符桿方向規則 (Stem Direction)

• 位於第 3 線（中線）以上的音符：符桿一律朝下（畫在符頭左側）。
• 位於第 3 線以下的音符：符桿一律朝上（畫在符頭右側）。
• 剛好在第 3 線正中央的音符：符桿朝上或朝下皆可，通常配合前後相鄰音符的方向以維持視覺整齊。
